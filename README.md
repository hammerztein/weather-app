# The Odin Project - Weather Application

This is a weather application built for [The Odin Project](https://www.theodinproject.com/) JavaScript course, based on the asynchronous code and working with APIs chapters.

## Assignment

Create a weather application using [Visual Crossing](https://www.visualcrossing.com/weather-api/) API and asynchronous code.
Application should be able to fetch and render data from an API endpoint and have a temperature unit toggle.
Optionally application should display loading component while Promise is in a pending state

## What I Learned

- How to fetch data from an API endpoint
- How to throw an Error object

## Features

- Search for weather by location
- View current conditions, a 7-day forecast, and weather insights
- Toggle temperatures between Celsius and Fahrenheit without fetching again
- See a loading indicator while weather data is being fetched
- Get an error dialog if weather data cannot be loaded
